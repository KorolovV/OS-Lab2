### 14) Як визначити тип файлу у системі, які типи файлів бувають?

У Linux все є файлом. Основні типи файлів, які можна зустріти за допомогою команди file або за першим символом у виводі ls -l, включають:

Звичайний файл (-) — містить дані, програми, текстові документи, наприклад, звичайний скрипт чи документ.

```
student@CsnKhai:/$ file /etc/passwd
/etc/passwd: ASCII text
```

Каталог (d) — спеціальний файл, який містить список інших файлів та папок, наприклад, /etc, /home.

```
student@CsnKhai:/$ file /etc
/etc: directory
```

Символьне посилання (l) — вказівник на інший файл або шлях, ярлик, наприклад, /dev/cdrom -> sr0.

```
student@CsnKhai:/$ file /dev/cdrom
/dev/cdrom: symbolic link to `sr0'
```

Блоковий пристрій (b) — пристрій зберігання даних із доступом блоками, наприклад, жорсткий диск /dev/sda.

```
student@CsnKhai:/$ file /dev/tty
/dev/tty: character special
```

Символьний пристрій (c) — пристрій для поточної символьної передачі даних, наприклад, термінал /dev/tty чи /dev/null.

```
student@CsnKhai:/$ file /dev/sda1
/dev/sda1: block special
```

Іменований канал або сокет (s / p) — використовуються для міжпроцесної взаємодії, наприклад, системні сокети у /dev/log.

```
student@CsnKhai:/$ file /dev/log
/dev/log: socket
```
